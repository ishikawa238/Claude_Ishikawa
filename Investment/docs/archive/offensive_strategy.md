# 攻め口座向け・2倍/3倍株狙いの戦略変更案

> **位置づけ**: 本書は「攻め口座」向けの運用戦略書である。守りのインデックス投資は別口座で行う前提で、本口座では個別株による大きなリターンを狙う。
>
> **システム実装**: `config.json` の `strategy_mode = "offensive"` で本ルールがシステム全体に適用される。`defensive` に戻せば現行の守りルールに復帰する。

## 1. 戦略変更の目的

この口座では、守りのインデックス投資ではなく、個別株による大きなリターンを狙う。

主な目的は以下。

- 2倍・3倍になる可能性のある成長株・テーマ株を狙う
- 短期の小さな利益確定だけでなく、勝ち銘柄を大きく伸ばす
- 含み損銘柄を長く持たず、損切りを徹底する
- 資金を広く薄く分散しすぎず、有望銘柄に集中する
- ただし、1回の失敗で口座全体が大きく傷つかないようにする

---

## 2. 現在の戦略の課題

現在の戦略は、短期〜中期の利益を積み上げるには有効である。

一方で、2倍・3倍株を狙うには以下の課題がある。

| 課題 | 内容 |
|---|---|
| 利確が早い | +0.5Rや+1Rで売ると、大化け銘柄を早く手放しやすい |
| 保有銘柄が増えやすい | 銘柄数が多いと、当たり銘柄の利益インパクトが小さくなる |
| 買い候補を広く拾いすぎる | 2倍・3倍を狙うには、より強い銘柄に絞る必要がある |
| 勝ち銘柄の買い増しルールが弱い | 上昇銘柄に追加で乗る仕組みが必要 |
| 損切りと利確の目的が混在している | 短期利確枠と大化け狙い枠を分ける必要がある |

---

## 3. 新しい基本方針

攻め口座では、以下の方針に変更する。

```text
弱い候補を広く買うのではなく、
強い候補だけを小さく買い、
勝ち銘柄だけを伸ばし、
さらに強さが確認できた銘柄だけ買い増す。
```

### 戦略の方向性

| 項目   | これまで       | 変更後              |
| ---- | ---------- | ---------------- |
| 目的   | 短期〜中期の利益確定 | 2倍・3倍株の発掘        |
| 銘柄数  | 最大10銘柄     | 5〜8銘柄程度に絞る       |
| 利確   | 早めに分割利確    | 一部だけ利確し、残りを長く伸ばす |
| 買い増し | 控えめ        | 勝ち銘柄のみ買い増し       |
| 損切り  | 通常通り実施     | より厳格に実施          |
| 重点   | 勝率         | 損小利大             |

---

## 4. 銘柄選定ルール

2倍・3倍株を狙うため、買い候補は今までより厳しく選別する。

### 優先して買い候補にする条件

| 条件                        | 理由             |
| ------------------------- | -------------- |
| スコア80以上                   | システム上の総合評価が高い  |
| SランクまたはAランク               | 弱い候補を除外する      |
| 52週高値更新または上場来高値更新         | 大相場入りの可能性がある   |
| 出来高が20日平均の2倍以上            | 資金流入が確認できる     |
| MA5 > MA25 > MA75 > MA200 | 上昇トレンドが明確      |
| RSIが50〜75程度               | 強いが過熱しすぎていない   |
| 決算・上方修正・増配・テーマ材料がある       | 株価上昇の理由がある     |
| 時価総額が大きすぎない               | 2倍・3倍の余地が残りやすい |

---

## 5. 見送りルール

攻め口座でも、何でも買うわけではない。

以下に当てはまる銘柄は、買い候補から外す。

| 見送り条件         | 理由                |
| ------------- | ----------------- |
| RSI80以上       | 短期過熱が強すぎる         |
| 長い上ヒゲをつけた     | 高値圏で売り圧力が出ている可能性  |
| 出来高急増後に陰線     | 利確売りが優勢の可能性       |
| 数日で30%以上急騰済み  | 高値掴みリスクが大きい       |
| 材料がSNSや思惑だけ   | 継続性が低い            |
| 業績が悪いのに株価だけ上昇 | 反落リスクが高い          |
| 損切り幅が15%以上    | リスク管理が難しい         |
| 板が薄すぎる        | 売りたい価格で売れない可能性がある |

---

## 6. エントリールール

### 基本ルール

```text
1. スコア80以上、S/Aランクを中心に見る
2. 52週高値更新、出来高2倍以上、MA整列を重視する
3. 決算・上方修正・増配・強いテーマがある銘柄を優先する
4. RSI80以上、長い上ヒゲ、急騰しすぎは見送る
5. 新規購入は1銘柄あたり口座全体の5〜10%まで
6. 損切りラインを決めてから買う
7. 損切り幅が広すぎる場合は株数を減らす
```

---

## 7. ポジションサイズルール

2倍・3倍株を狙うには、ある程度の集中投資が必要。ただし、最初から大きく入れすぎない。

### 基本の投入比率

| 状況         |      投入比率の目安 |
| ---------- | -----------: |
| 新規エントリー    |   口座全体の5〜10% |
| 強い含み益が出た銘柄 | 最大15〜20%まで許容 |
| 1銘柄の上限     |      原則20%以内 |
| 損切り時の許容損失  |  口座全体の1〜2%以内 |
| 現金比率       | 20〜30%を目安に残す |

---

## 8. 利確ルール

2倍・3倍株を狙うため、利確は早すぎないようにする。

### 攻め口座用の利確ルール

第2・第3利確のR倍率を大きく取り、残り40%を大化け枠として MA25/MA50 のトレーリングで保有する。

| 状況      | 対応                     |
| ------- | ---------------------- |
| +1R到達   | 20%だけ利確し、損切りラインを買値へ引き上げる |
| +3R到達   | さらに20%だけ利確、損切りを+1Rへ |
| +5R到達   | さらに20%だけ利確、損切りを+3Rへ |
| 残り40%   | MA25/MA50 のトレーリングで保有（大化け枠） |
| 株価2倍達成  | 残量の半分を利確を検討 |
| 株価3倍狙い  | 残りをMA50割れまで保有 |

### 大化け枠と短期回収枠の分け方

同じ銘柄の中でも、役割を分ける。

| 枠     | 目的        | 売却ルール           |
| ----- | --------- | --------------- |
| 短期回収枠（60%） | 利益を段階的に確保する | +1R / +3R / +5R で 20% ずつ売却 |
| 大化け枠（40%）  | 2倍・3倍を狙う  | MA25 割れで半分、MA50 割れで全量売却 |

---

## 9. トレーリングストップルール

| 状況         | 売却ライン                |
| ---------- | -------------------- |
| 上昇初期       | 当初の損切りライン            |
| +1R到達      | 損切りを買値付近へ引き上げ |
| +3R到達      | 損切りを+1R付近へ引き上げ |
| +5R到達      | 損切りを+3R付近へ引き上げ |
| MA25に沿って上昇 | MA25割れで短期回収枠を売却 |
| 強い大相場      | MA50割れまで大化け枠を保有 |

---

## 10. 買い増しルール

2倍・3倍を狙うには、勝ち銘柄への買い増しが重要。
ただし、買い増しは「下がったから買う」のではなく「強さが確認できたから追加する」場合だけ行う。

### 買い増ししてよい条件

| 条件           | 内容            |
| ------------ | ------------- |
| 含み益が+10%以上   | すでに勝っている銘柄である |
| MA25を維持      | 上昇トレンドが崩れていない |
| 出来高が維持または増加  | 資金流入が続いている    |
| 直近20日高値を再突破  | 上昇再開の確認       |
| 株価2倍未満       | 大化け枠を温存       |
| 追加後も1銘柄20%以内 | 集中しすぎを防ぐ      |

### 買い増ししてはいけない条件

| 条件           | 理由         |
| ------------ | ---------- |
| 含み損中         | ナンピンになりやすい |
| MA25割れ       | トレンド崩れの可能性 |
| 長い上ヒゲ後       | 天井圏の可能性    |
| RSI80以上の急騰直後 | 高値掴みリスクが高い |
| 損切りラインを下げる前提 | リスク管理が崩れる  |
| 決算前に無理に追加    | イベントリスクが高い |

---

## 11. 損切りルール

攻め口座では、損切りをより厳格にする。
理由は、2倍・3倍株を狙う戦略では外れ銘柄も多くなるため。

### 基本ルール

```text
1. 損切りラインを割ったら撤退
2. 損切りラインを下げない（システム側で原則ブロック）
3. 含み損銘柄を買い増ししない
4. 決算でシナリオが崩れたら撤退
5. MA25を明確に割ったら短期回収枠を売却
6. MA50を割ったら大化け枠も撤退検討
```

---

## 12. 保有銘柄数のルール

|  保有銘柄数 | 評価              |
| -----: | --------------- |
|  3〜4銘柄 | 集中度が高いがリスクも大きい  |
|  5〜8銘柄 | 攻めと分散のバランスが良い   |
| 9〜10銘柄 | やや分散しすぎ         |
|  10銘柄超 | 大化け銘柄の効果が薄まりやすい |

## 14. 重要な考え方

```text
2倍・3倍株を狙う戦略では、
すべての銘柄で勝つ必要はない。

大事なのは、
小さく負けて、
勝ち銘柄を大きく伸ばすこと。
```

| 考え方        | 内容            |
| ---------- | ------------- |
| 損小利大       | 負けは小さく、勝ちは大きく |
| 早すぎる利確を避ける | 大化け銘柄を残す      |
| 勝ち銘柄に乗る    | 含み益銘柄だけ買い増す   |
| 負け銘柄を助けない  | ナンピンしない       |
| 強い銘柄を残す    | 弱い銘柄は入れ替える    |
| 現金を残す      | チャンスに備える      |

## 16. 切替手順

1. `config.json` の `strategy_mode` を `"offensive"` に変更する（または `/settings` 画面から切替）。
2. 次のバッチ実行（`batch_evening_jp` / `batch_morning_all`）から新ルールが適用される。
3. Slack 通知のヘッダに `⚔ 攻めモード` バッジが表示されることを確認する。
4. 戻すときは `strategy_mode` を `"defensive"` に戻す。挙動は完全に現行互換となる。
