IdeaScout — アプリ事業アイデア自動発掘システム（凍結中）

■ コンセプト
毎朝、自分専用の「アプリ事業アイデア新聞」をMarkdown形式で生成する。
SNSや技術系サイトから「アプリ開発で解決できそうな課題」を定期収集・分析するリサーチBot。

■ 対象ソース
- Reddit（PRAW / OAuth API）
- Qiita（REST API）
- Zenn（RSS）
- YouTube コメント（Phase 2）

■ 対象ジャンル
- 英語学習
- 投資・家計管理
- 業務効率化
- 生活改善
- 筋トレ・健康管理

■ 出力
Markdownレポート + Slack通知サマリー

■ レポート項目
- 課題の要約
- 対象ユーザー
- MVP案
- 収益化案
- スコア（痛みの強さ / 市場規模 / 継続利用性 / 課金可能性 / 開発容易性 / 競合の少なさ）

■ MVPスコアリング（3軸・55点満点 → 100点換算）
- 痛みの強さ: 30点
- 開発容易性: 10点
- 課金可能性: 15点

■ 技術構成
- Python + SQLite + Claude API (Haiku) + Slack Webhook
- .env でAPIキー管理、config.json で設定管理
- 月コスト見込み: 約800円（Haiku, 50投稿/日分析）

■ 実行タイミング
毎日6:30収集開始 → 7:00レポート生成

2026-04-28 に凍結判断。Step 1（骨格 + DB初期化）まで完了済み。
