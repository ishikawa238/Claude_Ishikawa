初回セットアップ / タスク再登録

全システムの Windows タスクスケジューラを一括登録する。管理者権限が必要。

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup_all.ps1

稼働状態チェック (CLI)

全タスクの登録状態と最終実行結果を PowerShell で確認する。管理者権限不要。

.\status.ps1

Investment Dashboard

投資判断ダッシュボード。保有銘柄・シグナル・パフォーマンスなどを閲覧可能。

http://127.0.0.1:5100/report

このダッシュボードの起動

watchdog/ ディレクトリで起動。通常はログオン時にタスクスケジューラから自動起動。

cd watchdog
python run_dashboard.py

共通アーキテクチャ

Python 3.10+ / SQLite (WAL) / Slack Incoming Webhook / Windows タスクスケジューラ。共通モジュールは shared/ パッケージ (config, db, slack, logger)。

新システム追加時

batch_run_log テーブルを持つ DB があれば自動発見される（「未登録」バッジで表示）。config.json に登録して正式監視対象にする。

watchdog/config.json → projects
