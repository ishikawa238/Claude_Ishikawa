# リリースノート

Web 画面の「🆕 お知らせ」ページに表示されます。
新しい版は上に追加します。形式: `## v<版> — <YYYY-MM-DD> <タイトル>` の下に `- ` の箇条書き。

## v1.2.0 — 2026-11-19 英語学習機能
- 📖 エピソードの英語を自動で文字起こし（PC 内の Whisper。毎朝 09:00 と、学習ページから1話ずつ）
- 🇯🇵 1文ずつの和訳と、日本語の要約を表示（Claude）
- 🎧 学習ページでブラウザ再生。いま話している文がハイライトされ、文をクリックするとそこから再生
- 🔁 1文リピート・0.75倍速・和訳を隠して聞き取り練習
- 🃏 覚えるべき単語・フレーズを自動で抜き出し、単語帳でカード復習（間隔をあけて出題）
- 🆕 このお知らせページを追加

## v1.1.0 — 2026-11-19 アートワーク付きの新しい画面
- 🎨 音楽アプリ風のダークテーマに一新
- 🖼 番組・エピソードのジャケット画像を大きく表示（画像がない番組は頭文字のタイル）
- 📝 エピソードをクリックすると紹介文を表示
- ⏰ 時間割を 24 時間のタイムラインで表示

## v1.0.0 — 2026-11-19 EnglishRadio 誕生

- 💬 Slack に今日のラインナップを通知
- 🖥 Web 管理画面（状況・今日のリスト・過去のリスト・ライブラリ・番組・時間割）
