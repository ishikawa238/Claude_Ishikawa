# EnglishRadio

毎朝、英語のポッドキャストを自動で流すシステム。旧 `MorningPlaylist`（Spotify 版）の後継。

Spotify 版は、Spotify の認証が切れるたびにブラウザで手作業の再認証が必要だった（2026-10-25 から停止）。
EnglishRadio は **認証のいらないポッドキャスト RSS** から mp3 を直接ダウンロードし、**PC の VLC で再生する** ので、認証切れで止まることがない。

## 仕組み

1. 毎朝 07:00（時間割で変更可）にタスクスケジューラが PC をスリープから起こして起動
2. 各番組の RSS から最新エピソードを確認し、まだ持っていないものだけ mp3 をダウンロード
3. **新着を優先**して、時間割の長さ（例: 07:00〜08:30 なら 90 分）に収まるリストを作る
4. 時間が余ったら、これまで貯めた mp3 から **未再生 → しばらく聞いていない順にシャッフル** で埋める
5. VLC で再生し、Slack に「今日のラインナップ」を通知
6. 新着がない日でもライブラリから流れる（mp3 は削除せずに貯めていく）

## Web 管理画面

http://127.0.0.1:5210/ （このPCからだけ開けます。ログオン時に自動起動）

| ページ | できること |
|---|---|
| 🏠 状況 | 今日再生できたか、次の予定、予約の状態、最近の実行、ライブラリの量、VLC の有無 |
| 🎧 今日のリスト | 今朝のリスト（🆕新着 / 🔀ライブラリから）。もう一度再生、新着を取り直して再生 |
| 🗓 過去のリスト | 日付ごとのリストと中身。好きな日のリストをもう一度再生 |
| 📚 ライブラリ | 貯めたエピソードの一覧。番組で絞り込み・タイトル検索・1話だけ再生 |
| 🎙 番組 | RSS の URL で番組を追加（中身を確認してから保存）、お休み・削除 |
| ⏰ 時間割 | 開始・終了時刻と曜日（毎日 / 平日 / 土日）。保存するとタスクスケジューラにも反映 |
