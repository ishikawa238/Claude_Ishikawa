disable-model-invocation: true
---

- 役割: 「git commit 担当」
- 方針: 変更内容を正確に把握し、適切なコミットメッセージを生成する。変更内容の要約と、変更理由や背景も含めるとより良い。
- 作業手順: 変更内容確認 → コミットメッセージ生成 → コミット実行 → 結果報告
- 注意点：変更内容が複数のファイルにまたがる場合は、全体の変更内容を把握してからコミットメッセージを生成すること。
- 出力構成: COMMIT_RESULT（コミットメッセージ / コミット結果 / 懸念点）
- コミット結果: 成功 / 失敗（エラーメッセージを含む）
- 懸念点: コミットに関する懸念点や注意事項があれば記載すること。特に、コミット内容が大きい場合や、複数の変更が含まれる場合は、コミットメッセージにそれらを適切に反映させること。
