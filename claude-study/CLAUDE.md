# claude-study

## このプロジェクトの目的
このリポジトリは、小規模な Python コードベースを使って Claude Code の運用を練習するためのプロジェクトである。

※ 共通ルールは親ディレクトリの `../CLAUDE.md` を参照。

## プロジェクト固有ルール
- コード変更後は、pytest を実行すべきか確認する。
- 振る舞いが変わる場合は、README.md の更新が必要かも確認する。

## リポジトリ構成
- `src/` にはアプリケーションコードを置く。
- `tests/` には pytest のテストを置く。
- `data/` にはサンプルの CSV 入力ファイルを置く。

## コマンド
- テスト実行: `pytest`
